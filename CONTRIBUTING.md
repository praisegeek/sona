# Contributing to Sona

First off, thank you for taking the time to contribute! Sona is an open-source, peer-to-peer music protocol built to replace centralized streaming giants. Because we run on zero platform server costs and decentralized infrastructure, community collaboration is the lifeblood of this project.

## Code of Conduct

By participating, you are expected to uphold our community standards:
- Be respectful and welcoming to contributors from all backgrounds, languages, and skill levels.
- Focus on what is best for the community and the protocol.
- Accept constructive criticism gracefully.

## How Can I Contribute?

There are many ways to contribute beyond writing code:
- **Sharing Code:** Fixing bugs, building UI components, or improving the P2P streaming engine.
- **Translating:** Helping make Sona accessible in music communities worldwide across all languages.
- **Testing & QA:** Testing cross-platform builds (iOS, Android, Desktop) and reporting issues.
- **Documentation:** Improving guides, architecture breakdowns, and developer onboarding.

---

## Submitting Contributions

### 1. Reporting Issues
If you find a bug or have a feature request, please check the [Issue Tracker](../../issues) first to ensure it hasn't already been reported. When opening a new issue, include:
- A clear, descriptive title.
- Steps to reproduce the bug (if applicable).
- Environment details (OS, device, client version).

### 2. Pull Request (PR) Process
1. **Fork the repository** and create your branch from `main`.
2. **Make your changes** ensuring code style and architectural principles (e.g., P2P-first, zero server bloat) are respected.
3. **Test your changes** locally across relevant environments.
4. **Submit a Pull Request** with a clear description of the problem solved or feature added.

## Development Setup

*Instructions for running Sona locally:*

1. Clone the repository:
   ```bash
   git clone https://github.com/praisegeek/sona
   cd sona
   ```

 * Install dependencies:
   ```bash
   npm install
   ```
 * Run the development environment:
   ```bash
   npm run dev
   ```
   
## Questions or Ideas?
If you want to discuss a major architectural change or pitch a new feature (like remix studio additions or discovery enhancements), open an issue labeled discussion or start a conversation in our community channels.
Thank you for helping keep music free, decentralized, and alive forever!
